# Investment Dashboard

An interactive dashboard for tracking stock market investments. Users will be able to create and manage investment portfolios to monitor and analyze their investments.

## Basic Environment Setup

Create a virtual environment to isolate project dependencies and configuration from other projects and the system-wide Python installation.

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Upgrade the package manager (pip) and install the project dependencies from the `requirements.txt` file.

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Running the Application

To start the application, run:

```bash
streamlit run app.py
```

The application will be available in your web browser. If it does not open automatically, follow the URL displayed in the terminal.
